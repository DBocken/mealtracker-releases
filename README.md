# Mealtracker – Releases

Hier liegen nur die fertigen Android-Dateien (APK) des Mealtrackers, kein Quellcode.

**Erste Installation:** Unter [Releases](https://github.com/DBocken/mealtracker-releases/releases/latest) die neueste `mealtracker-….apk` auf das Handy laden und öffnen. Android fragt einmal, ob Installationen aus dieser Quelle erlaubt sind.

**Updates:** In der App unter **Mehr → App-Update**. Die App lädt die neue Version von hier und öffnet die Installation; deine Einträge bleiben erhalten.
